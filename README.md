# Service Booking Project

## About

I made this project to practice HTML, CSS and JavaScript.

The project lets the user:
- View different services
- Add services to the cart
- Skip to the next service
- Fill the booking form

## My Learning Process

Step 1:
I first created the HTML layout with the service card and booking form.

Step 2:
Then I displayed one service using JavaScript.

Step 3:
After that I made the **Add Item** button work so the selected service is added to the cart.

Step 4:
Next I added the **Skip Item** button to show the next service.

Step 5:
Finally I added the booking form validation to check that all fields are filled and at least one service is added before booking.

## What I Learned

- How to use getElementById()
- How to update HTML using JavaScript
- How to use arrays to store data
- How to use button click events
- How to validate form inputs

## Problems I Faced

At first I did not know how to update the cart after clicking the Add button.

I also found it difficult to calculate the total price.

After testing the code and fixing small mistakes, I understood how to update the page using JavaScript.

## How to Run

1. Download or clone the project.
2. Open the project folder.
3. Open `index.html` in your browser.
