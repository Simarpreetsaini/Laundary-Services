# Service Booking Project

## About

I made this project to practice HTML, CSS and JavaScript.

The project lets users:

* View different services
* Add services to the cart
* Skip to the next service
* See the total price
* Fill the booking form
* Book a service

## What I Learned

* How to use `getElementById()`
* How to update HTML using JavaScript
* How to use arrays to store service data
* How to use button click events
* How to add items to a cart
* How to calculate the total price
* How to validate form inputs
* How to separate sections using CSS

## Problems I Faced

At first, I had difficulty updating the cart and calculating the total price. After testing and fixing the code, I understood how JavaScript updates the webpage.

## How to Run

1. Open the project folder.
2. Open `index.html` in a browser.
